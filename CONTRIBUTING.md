# Contributing

1. Do not submit code or assets copied from paid courses, private repositories,
   employers, customers, or sources without a compatible license.
2. Do not commit `.env`, credentials, production data, internal documentation,
   generated indexes, logs, or model traces containing private content.
3. Add focused tests for behavior changes and run `./run.sh --verify` or
   `.\run.ps1 --verify` before opening a pull request.
4. Add attribution and license notices for every incorporated third-party work.
5. Keep protocol and safety claims narrower than the behavior proven by tests.
